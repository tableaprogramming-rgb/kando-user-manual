# Welcome, HR Admin! 👨‍💻

You hold the keys to the castle! As an HR Admin, you configure how Kando works for the entire organization. Your setup determines how easy life is for every employee and manager.

This guide takes about **30 minutes** to complete.

---

## ✅ System Setup Checklist

### 1. [ ] Configure Organization Details
**Goal**: Brand your workspace.
- Go to **Settings** → **Organization**.
- Upload Company Logo.
- Set Timezone and Date Format.
- *Time: 5 mins*

### 2. [ ] Define Leave Policies
**Goal**: Set the rules for time off.
- Go to **Settings** → **Policies** → **Leave**.
- Configure "Annual Vacation" (e.g., 15 days/year).
- Configure "Sick Leave" (e.g., 10 days/year).
- Set rules like "Requires approval?" or "Allows negative balance?".
- *Time: 10 mins*

### 3. [ ] Create Departments
**Goal**: Organize your people.
- Go to **Organization** → **Departments**.
- Create your main buckets (e.g., "Sales", "Engineering", "Support").
- Assign a "Head of Department" if known.
- *Time: 5 mins*

### 4. [ ] Add Your First Users
**Goal**: Populate the system.
- Go to **People** → **Directory**.
- Click **Add Person**.
- Try adding yourself (if not already) or a test user.
- Assign them to a Department and a Role.
- *Time: 5 mins*

### 5. [ ] Assign Managers
**Goal**: Build the reporting lines.
- Go to a user's profile.
- Find the "Reports To" field.
- Select their Manager. This enables approval workflows!
- *Time: 2 mins*

### 6. [ ] Configure Work Schedules
**Goal**: Define standard working hours.
- Go to **Settings** → **Schedules**.
- Create a "Standard 9-5" template.
- Assign it to your test user.
- *Time: 3 mins*

### 7. [ ] Payroll Basics (Optional)
**Goal**: Prepare for pay day.
- Go to **Payroll** → **Settings**.
- Set your Pay Period (Weekly, Bi-weekly, Monthly).
- *Time: 5 mins*

---

## 💡 Admin Power Tips

- **Bulk Import**: Don't add 100 users by hand! Use the **CSV Import** tool in the People section to upload your whole staff list at once.
- **Impersonation**: Need to troubleshoot? You can "View As" an employee to see exactly what they see.
- **Audit Logs**: Every change you make is recorded in the Audit Log for security and compliance.
