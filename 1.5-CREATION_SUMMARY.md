## Content Highlights

### The Four Roles (Quick Summary)

```
Owner (👑)
└─ Full system access
   ├─ System management
   ├─ All employees visible
   ├─ All reports
   └─ Billing & subscriptions

Manager (👨‍💼)
└─ Team management only
   ├─ View/manage direct reports
   ├─ Approve team requests
   ├─ Create team schedules
   └─ View team reports

HR Admin (👨‍💻)
└─ HR functions
   ├─ Configure leave types
   ├─ Set up payroll
   ├─ Manage all employees
   └─ Finalize payroll

Employee (👤)
└─ Self-service only
   ├─ Clock in/out
   ├─ Request leave
   ├─ Submit timesheet
   └─ View own data
```

### The Three-Layer Permission Model

```
Layer 1: Role-Based (Owner, Manager, HR Admin, Employee)
         "What features can I access?"

Layer 2: Hierarchy-Based (Team membership)
         "What data can I see?"

Layer 3: Workflow-Based (Approval assignments)
         "What requests can I act on?"

Final Permission = Layer 1 AND Layer 2 AND Layer 3
```

### Permission Check Example

```
Manager tries to approve leave from Employee B

✓ Is user a Manager? YES
✓ Is Employee B in manager's team? YES
✓ Is manager in approval workflow? YES

Result: APPROVED ✅
```
