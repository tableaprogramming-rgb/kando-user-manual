# Kando User Manual

Welcome to the **Kando User Manual** - your complete guide to using the Kando workforce management system.

## 🎯 What is Kando?

Kando is a comprehensive **workforce management system** that helps organizations manage:
- ⏱️ Time & Attendance tracking
- 📅 Leave and absence management
- 📊 Schedule creation and management
- 💰 Payroll and compensation
- ✅ Approval workflows
- 📈 Reporting and analytics
