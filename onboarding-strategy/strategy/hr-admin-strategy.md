# HR Admin Onboarding Strategy

## 🎯 Goal
Get the HR Admin to **Configure Core Settings** and **Add their First User** within the first 30 minutes.

## 👤 User Mindset
- "I need to set this up correctly for the whole company."
- "I don't want to make a mess of the data."
- "How do I get my people in here?"
- "Is payroll going to work?"

## 🗺️ The "Happy Path"
Unlike others, HR Admins enter a **Setup Wizard** immediately upon first login:
1. **Organization Details**: Name, Logo, Timezone.
2. **Policy Defaults**: Set standard work hours (e.g., 9-5) and default leave allowance (e.g., 15 days).
3. **Departments**: Create initial departments (e.g., Sales, Eng).
4. **Add Users**: Bulk upload or manual add of first few employees.
5. **Completion**: Drop them onto the Dashboard with the "System Setup" checklist.

## ✅ Onboarding Milestones (Checklist)
This checklist appears on the Admin Dashboard:
1. **System Basics**: Org name, logo, timezone.
2. **Define Policies**: Set Vacation/Sick leave accrual rules.
3. **Create Departments**: Set up org structure.
4. **Add Employees**: Invite users or bulk import CSV.
5. **Configure Payroll**: Set pay periods and bank templates.
6. **Assign Managers**: Link employees to their supervisors.

## 💡 Convenience Features
- **Setup Wizard**: Don't make them hunt for settings. Bring the settings to them in a linear flow.
- **Templates**: Provide "Standard Policy Templates" (e.g., "Standard US Policy", "Standard UK Policy") they can apply with one click.
- **Bulk Import**: Prominent "Import from Excel/CSV" feature for adding users.
- **Sandboxing**: Allow them to clear test data easily before "Going Live".
