# HR Admin Onboarding Strategy

## 🔑 Prerequisites
**Organization Owner has already completed:**
- ✅ Organization profile (name, logo, billing contact)
- ✅ Organization settings (timezone, date/time format)
- ✅ Verified billing email
- ✅ Assigned at least one seat to you (HR Admin)

**You (HR Admin) now unblock Managers and Employees.**

---

## 🎯 Goal
Get the HR Admin to **Define Policies, Create Users, Build Organization Structure, and Assign Managers** within the first 25 minutes.

## 👤 User Mindset
- "Organization setup is done. How do I get people into the system?"
- "I need to define policies before employees start requesting time off."
- "How do I organize the company structure?"
- "Are approval workflows set up correctly?"

## 🗺️ The "Happy Path"
HR Admins enter a **Setup Wizard** immediately upon first login (org details already pre-configured):
1. **Policy Defaults**: Set standard work hours (e.g., 9-5) and default leave allowance (e.g., 15 days).
2. **Departments**: Create initial departments (e.g., Sales, Eng).
3. **Add Users**: Bulk upload or manual add of first few employees.
4. **Assign Roles**: Make sure roles are set (critical for system access).
5. **Completion**: Drop them onto the Dashboard with the "People Setup" checklist.

## ✅ Onboarding Milestones (Checklist)
This checklist appears on the Admin Dashboard:
1. **Define Policies**: Set Vacation/Sick leave accrual rules.
2. **Create Departments**: Set up org structure.
3. **Add Employees**: Invite users or bulk import CSV.
4. **Assign Roles**: Critical—new users need roles to access system.
5. **Assign Managers**: Link employees to their supervisors for approval workflows.
6. **Configure Payroll**: Set pay periods and bank templates.

## 💡 Convenience Features
- **Setup Wizard** (Policy/Department/Users focused): Don't make them hunt for settings. Bring the settings to them in a linear flow. Organization details pre-filled from Owner setup.
- **Templates**: Provide "Standard Policy Templates" (e.g., "Standard US Policy", "Standard UK Policy") they can apply with one click.
- **Bulk Import**: Prominent "Import from Excel/CSV" feature for adding users with role assignment required.
- **Role Assignment Required**: Make role assignment mandatory during user creation—users without roles cannot access system.
- **Sandboxing**: Allow them to clear test data easily before "Going Live".

## ⚠️ Critical Handoff from Owner
- Owner assigned you (HR Admin) a subscription seat
- You can now access Kando as HR Admin
- Your job: Create users so Managers and Employees can login and onboard
- Until you create users: No one except Owner can access the system
