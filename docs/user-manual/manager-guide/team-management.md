# Team Management

*Manage your team members, schedules, performance, and operations in Kando.*

## Overview

Team Management allows you to:
- View and manage your team roster
- Assign shifts and schedules
- Monitor team attendance and time tracking
- View team performance metrics and KPIs
- Communicate with team members
- Manage team requests and approvals
- Track team productivity
- Generate team reports
- Manage team documents and records
- Handle performance evaluations and feedback

As a manager, Kando is your hub for all team-related operations. You can track individual and team performance, manage schedules, review requests, and generate reports for business insights.

## Common Tasks

### Review Daily Attendance

**Morning Check-In**:
1. Navigate to **Team** → **Attendance**
2. View **Today** tab (default)
3. See all team members with status:
   - 🟢 Present: Successfully clocked in
   - 🟡 Late: Clocked in after start time
   - 🔴 Absent: Not yet clocked in
   - ⚪ On Leave: Approved leave scheduled
4. Filter by status to focus on issues
5. Send reminders to late arrivals (optional)

**Action for No-Shows**:
- Click **Absent** team member
- Send message: "Good morning, please update your status"
- Or call if emergency
- Document in their record if repeated

### Approve Leave Requests

**New Leave Request Notification**:
1. Receive notification: "Maria requested 2 days leave (Feb 17-18)"
2. Navigate to **Team** → **Requests**
3. See **Pending** tab with new requests
4. Click request to review:
   - Employee name and ID
   - Leave type (Vacation, Sick, Personal)
   - Dates requested
   - Reason provided
   - Employee's leave balance
   - Team coverage impact

**Approve Request**:
1. Click **Approve** button
2. Add optional note: "Approved. Please hand over projects."
3. Click **Submit**
4. Employee notified of approval
5. Leave appears on schedule and timesheet

**Reject Request**:
1. Click **Reject** button
2. Provide reason: "Coverage conflict. Can you request different dates?"
3. Click **Submit**
4. Employee notified; can revise request

**SLA**: Complete approvals within 24-48 hours

### Manage Team Schedule

**View Team Schedule**:
1. Navigate to **Schedule** → **Team Schedule**
2. Week view shows all team members
3. See:
   - Who's scheduled each day
   - Shift times for each person
   - Who's on leave
   - Schedule conflicts
4. Month view for overview planning

**Assign Shifts**:
1. Click **Create/Edit Schedule**
2. Select date range for scheduling
3. For each team member, assign shifts:
   - Click date cell
   - Select shift type (Morning, Afternoon, Night, Off)
   - Enter specific times if custom
4. Check for coverage:
   - Ensure adequate staffing each shift
   - Balance workload
   - Respect employee preferences (if recorded)
5. Click **Publish**
6. Team notified of schedule

**Common Scheduling Scenario**:
```
Week of Feb 16:
- Morning shift needs 3 people → assign Maria, John, Robert
- Afternoon shift needs 2 people → assign Ana, Jessica
- Night shift needs 1 person → rotate with Diego, Paolo
- Days off: 2 per week per employee
- Leave already: Ana (Mon-Wed), Robert (Fri)
```

### Approve Shift Swap Requests

**Shift Swap Scenario**: Employee A wants to swap with Employee B

**Notification Received**:
"Maria requested to swap Thursday shift with Jessica"

**Review Steps**:
1. Navigate to **Team** → **Requests** → **Swaps**
2. Click swap request
3. View details:
   - Both employees involved
   - Original shifts (who's scheduled when)
   - Proposed new arrangement
   - Both employees' agreement status
4. Verify:
   - Both employees are willing (both checked box)
   - Shift coverage not impacted
   - No scheduling conflicts
5. **Approve**: Both employees and shifts swap
6. **Reject**: If coverage issue or concern

**Coverage Check**:
- Before: Maria (Thu Morning), Jessica (Thu Afternoon) ✅ Covered
- After: Jessica (Thu Morning), Maria (Thu Afternoon) ✅ Still covered
- Result: Safe to approve

### Creating Manual Timelogs for Employees

**What Are Manager-Created Timelogs?**

Sometimes employees can't clock in/out themselves (system down, forgot, technical issue). As a manager, you can **create time entries for your team members** to ensure accurate records.

**Key Points**:
- Manager-created entries are distinct from employee entries
- They require proper documentation and reason
- They impact payroll, so accuracy is critical
- Should match employee's actual work hours
- Audited for compliance

#### When to Create Manual Timelogs

**Legitimate Reasons**:
✅ System was unavailable during shift
✅ Employee forgotten to clock in/out (occasional)
✅ Clock-in device malfunction
✅ Employee requested (with documentation)
✅ Shift worked but system didn't record

**NOT Appropriate**:
❌ To cover up unauthorized absences
❌ As favor for employee who ghosted
❌ Without documentation or evidence
❌ To inflate hours for bonus purposes
❌ Without employee acknowledgment

**Example Scenarios**:

| Scenario | Action |
|----------|--------|
| Kando down 9-11 AM, John worked | ✅ Create entry for 9-11 |
| Maria forgot to clock out | ✅ Create entry if she worked those hours |
| System glitch: entry not saved | ✅ Recreate based on evidence |
| Diego asked permission, forgot | ✅ Create with documentation |
| Staff worked through lunch | ✅ Adjust times to reflect actual hours |

#### How to Create Manual Timelog for Employee

**Step 1: Navigate to Employee Time Records**
1. Go to **Team** → **Time Management**
2. Select employee from list
3. Click **Create Time Entry** or **Add Manual Entry**

**Step 2: Enter Time Details**
```
Fill in:
├─ Employee: [Name auto-filled]
├─ Date: When they worked
├─ Start Time: Clock-in time (e.g., 9:00 AM)
├─ End Time: Clock-out time (e.g., 6:00 PM)
├─ Break Duration: Lunch break (e.g., 1 hour)
├─ Shift Type: (Morning, Afternoon, Night, etc.)
└─ Reason/Notes: WHY creating this entry
   └─ e.g., "System unavailable, employee confirmed hours worked"
```

**Step 3: Add Documentation**
- **Note**: Explain why entry needed
- **Evidence**: Reference any proof:
  - "Email from 9:15 AM"
  - "CCTV shows arrival at 8:55 AM"
  - "Employee request via message"
  - "Shift schedule confirms"

**Step 4: Notify Employee**
```
Message employee:
"I created a time entry for Feb 15: 9:00 AM - 6:00 PM.
System was down that morning. Please verify this matches
your actual hours. Reply to confirm."
```

**Step 5: Submit Entry**
1. Review all details once more
2. Click **Create** or **Add Entry**
3. System adds to employee's timesheet
4. Entry visible in employee's records
5. Employee is notified (depending on settings)

#### Impact on Employee's Timesheet

**What Happens**:
```
Before: Employee's timesheet for Feb 15
├─ No entry (system down)
└─ Status: Missing hours

After: Manager creates manual entry
├─ Entry added: 9:00 AM - 6:00 PM (8 hours)
├─ Status: Pending manager approval
└─ Shows as "Manager Added" label
```

**Employee Can**:
✅ View the entry in their timesheet
✅ Verify it's correct
✅ Request changes if wrong
✅ Provide documentation if needed

**Employee Cannot**:
❌ Edit manager-created entries
❌ Delete manager-created entries
❌ Claim false hours were entered

#### Approval Process for Manual Entries

**If Created by You (Direct Manager)**:
1. Entry automatically shows as "Created by Manager"
2. Your approval is assumed (you're the manager)
3. Entry flows to payroll (already approved)
4. No additional approval needed

**If Created by Different Manager**:
1. Entry shows "Created by [Manager Name]"
2. Requires your approval (original manager)
3. You review and approve/reject
4. Then flows to payroll

#### Scenarios: Creating Manual Entries

##### Scenario 1: System Downtime

**Situation**: Kando was down from 9-10 AM. Maria worked during that time.

**What Happened**:
- Maria clocked in at 8:45 AM (before outage)
- System went down 9 AM
- System back up 10 AM
- Maria clocked out at 5 PM
- System shows: 8:45 AM - ???? (gap during outage)

**Solution**:
1. View Maria's entry (shows incomplete)
2. Create adjustment or manual entry
3. Note: "System downtime 9-10 AM, filled in from schedule"
4. Final entry: 8:45 AM - 5:00 PM (8 hours 15 min)
5. Deduct 1 hour lunch = 7 hours 15 minutes worked

##### Scenario 2: Employee Forgot Clock-in

**Situation**: Diego worked but forgot to clock in (only clocked out)

**What Happened**:
- Diego worked 8 AM - 5 PM
- Forgot to clock in at 8 AM
- Only clocked out 5 PM (showing ???? - 5 PM)
- System can't calculate hours

**Solution**:
1. Ask Diego: "Did you work 8 AM as scheduled?"
2. If confirmed, create entry:
   - Start: 8:00 AM
   - End: 5:00 PM
   - Note: "Employee confirmed, forgot clock-in, clocked out at 5 PM"
3. System updates to show full 8 AM - 5 PM entry
4. Accurate hours for payroll

##### Scenario 3: Shift Request

**Situation**: Employee asks if they can work additional hours they forgot to clock

**Before Creating Entry**:
✓ Employee MUST confirm exact hours worked
✓ Manager MUST verify against schedule/evidence
✓ Should match with break documentation
✓ Need timestamp (email, message, CCTV)

**Creating Entry**:
1. Employee says: "I worked 8 AM - 5 PM Monday"
2. You verify against schedule: Confirmed 8 AM - 5 PM
3. You create entry with note: "Employee request to add hours, verified against schedule"
4. Employee acknowledges receipt
5. Entry approved and sent to payroll

#### Important Considerations

**Audit Trail**:
- Every manual entry shows "Created by [Manager]"
- Includes date/time of creation
- Original reason/notes are permanent record
- Can't be hidden or deleted

**Payroll Impact**:
- Manual entries affect employee's pay
- If hours are wrong, pay will be wrong
- Financial/legal consequences if intentional fraud
- Compliance audits review these entries

**Best Practices**:
✅ Always document WHY you created entry
✅ Notify employee and get confirmation
✅ Use objective evidence when possible
✅ Create entries ASAP (not weeks later)
✅ Consistent with company policy
✅ Keep records of approvals and confirmations
✅ Don't create entries without clear reason
✅ Review for accuracy before submitting

**Never Create Manual Entries For**:
❌ Personal favors
❌ Inflating hours to help employee bonus
❌ Covering unexcused absences
❌ False time (employee didn't actually work)
❌ To bypass approval workflows
❌ Without documentation or evidence

#### Requesting Changes to Manual Entries

**If You Made an Error**:
1. Don't delete the entry
2. Create a NEW correction entry
3. Add note: "Correction to Feb 15 entry - should be 8 AM not 7:30 AM"
4. Keep original for audit trail
5. Both entries visible in history

**If Employee Claims Entry is Wrong**:
1. Review your documentation
2. If wrong: Create correction entry
3. If correct: Explain reason to employee
4. Document employee's response
5. Keep records for audit

## Best Practices

✅ **DO**:
- **Check team daily** for attendance and status
- **Respond to requests within 24 hours** (leave, swaps, etc.)
- **Communicate schedule changes early** (at least 1 week advance)
- **Recognize high performers** regularly in announcements
- **Keep accurate records** of approvals and rejections
- **Follow leave policies consistently** (don't play favorites)
- **Monitor patterns** (absenteeism, late arrivals, overtime)
- **Provide feedback to team** on performance trends
- **Plan schedules fairly** considering employee preferences
- **Document issues** (absences, performance, conduct) properly

❌ **DON'T**:
- Approve requests without proper review of business impact
- Grant special treatment to some employees (bias)
- Miss approval deadlines (creates frustration)
- Make schedule changes last-minute without notice
- Ignore attendance or performance issues (address early)
- Overlook leave policy violations
- Schedule without balancing team member preferences
- Share sensitive team metrics publicly
- Forget to publish updated schedules
- Delay resolving employee disputes
- Assume absence without investigating
- Make emotional decisions on requests

## Managing Common Scenarios

### Scenario 1: Frequent Absenteeism

**Situation**: John frequently arrives late or calls in absent

**Actions**:
1. Document absences in system (date, time, reason)
2. After 3rd occurrence in month: Schedule discussion
3. Discuss patterns: "John, I noticed 3 absences this month. Is everything okay?"
4. Identify cause: Health issue, transportation, work dissatisfaction?
5. Provide support or address issue
6. Set expectations: "Going forward, I need at least 2 days notice for absence"
7. Follow up: Track improvement
8. Escalate to HR if pattern continues despite intervention

### Scenario 2: Shift Coverage Gap

**Situation**: Two people requested day off same date, leaving insufficient coverage

**Actions**:
1. When second request arrives, check coverage
2. Message requester: "Thursday is now understaffed if approved. Can you choose different day?"
3. If critical, offer alternatives:
   - Suggest different date
   - Ask if willing to work shift if critical
   - Find colleague to swap
4. Document decision: Approve first request, offer alternatives for second

### Scenario 3: Performance Issue

**Situation**: Maria's productivity dropped significantly

**Investigation**:
1. Review metrics: Check recent performance data
2. Compare to baseline: Is it recent change?
3. Analyze work: Quality vs. quantity issues?
4. Check personal: Any schedule/leave pattern changes?

**Action**:
1. Schedule private meeting: "I noticed productivity trend. Let's discuss."
2. Active listening: Understand employee perspective
3. Root cause: Workload, skill gap, personal issue, or other?
4. Develop plan: Training, resources, timeline for improvement
5. Follow up: Monitor progress, provide support

### Scenario 4: Schedule Conflict

**Situation**: High performer requested leave same week as major deadline

**Decision Process**:
1. Review: Is leave legitimate? Does employee have balance?
2. Assess impact: Project deadline, team coverage, alternatives?
3. Options:
   - Approve if team can handle
   - Discuss shifting dates with employee
   - Approve with contingency (employee completes key tasks before)
   - Offer alternative (unpaid leave, work remotely from vacation, partial week)
4. Communicate decision with reasoning
5. Document for future reference

## Troubleshooting

**Problem**: "I can't approve a leave request - button is grayed out"
**Cause**: Request may already be processed, or you lack permission
**Solution**:
1. Check if request was already approved/rejected
2. Verify you're the assigned manager for this employee
3. Refresh page if issue persists
4. Contact HR if permission issue

**Problem**: "Team member shows absent but they're actually present"
**Cause**: Employee hasn't clocked in yet, or system delay
**Solution**:
1. Verify employee actually clocked in (check their timesheet)
2. Wait a few minutes for system update
3. Ask employee to verify they clicked clock-in button
4. Manually mark present if system error confirmed
5. Contact support if persistent

**Problem**: "I accidentally rejected a leave request"
**Cause**: Human error in system
**Solution**:
1. Immediately inform employee
2. Re-review the request and approve if appropriate
3. Apologize for error
4. Document in system for future reference
5. Employee can resubmit if in error

**Problem**: "Can't see one employee in team list"
**Cause**: Employee may have been transferred to different team or inactive
**Solution**:
1. Check if employee is still assigned to your team (verify with HR)
2. If transferred, they'll now report to different manager
3. Check employee status (active vs. inactive)
4. If employee should be on your team, contact HR to reassign

**Problem**: "Schedule not publishing - error message appears"
**Cause**: Missing required information or system error
**Solution**:
1. Verify all shifts are assigned (no blank spots)
2. Check for scheduling conflicts
3. Ensure shift times are valid
4. Verify employee permissions are correct
5. Try saving as draft first, then publishing
6. Contact support if technical error
