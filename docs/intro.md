# Welcome to Kando Documentation 👋

**Kando** is a comprehensive **Human Capital Management System (HCMS)** that helps organizations streamline workforce management, from time tracking and leave management to payroll and scheduling.

This documentation portal provides everything you need to use Kando effectively.

## 📊 What is Kando?

Kando is a powerful HCMS that helps organizations manage:

- **⏱️ Time & Attendance** — Track work hours, attendance, and time entries
- **📅 Leave Management** — Submit and track leave requests
- **📊 Scheduling** — Create and manage employee schedules
- **💰 Payroll** — Process payroll and generate payslips
- **✅ Approval Workflows** — Streamline request approvals
- **📈 Reporting** — Generate insights from workforce data
