## What Was Created

A comprehensive **System Setup Requirements** guide that walks HR administrators and system implementers through **everything that must be configured** before Kando can be used.

### Page Structure

The 687-line page includes:

1. **Overview** - What needs configuring and timeline (2-8 hours)

2. **Phase 1: Organization & Access Groups Setup** (30-45 min)
   - Verify organization exists
   - Understand 4 access groups (Owner, Manager, HR Admin, Employee)
   - Verify access groups are configured

3. **Phase 2: Create Users & Employees** (1-2 hours)
   - Plan users and roles
   - Create user accounts with email and access group
   - Create employee records (linked to users)
   - Assign managers to employees

4. **Phase 3: Leave System Setup** (1-2 hours)
   - Create leave types (Vacation, Sick, Personal, Bereavement, etc.)
   - Initialize leave credits for each employee
   - Configure approval rules (optional)

5. **Phase 4: Scheduling Setup** (1-3 hours)
   - Create shift types (if using shifts)
   - Assign schedules to employees

6. **Phase 5: Payroll Setup** (1.5-2 hours)
   - Create payroll cycles
   - Assign employees to cycles
   - Create pay types
   - Collect employee compensation data
   - Configure periods

### Key Features

✅ **Clear Order Dependencies** - Explains why setup order matters
- LeaveTypes must be created BEFORE LeaveCredits
- Users created BEFORE Employees
- Employees assigned BEFORE Schedules

✅ **Effort Estimates** - Time for each phase and overall setup

✅ **Verification Checklist** - 20+ checkboxes to ensure nothing was missed:

✅ **Common Mistakes Section** - 5 troubleshooting scenarios:
- "Employees Can't Clock In" → No schedule created
- "Can't Request Leave" → No leave credit initialized
- "Manager Can't Approve Requests" → Not in approver list
- "User Can't Log In" → Email not verified or no access group
- "Can't Process Payroll" → Missing cycle, period, or pay type

✅ **Best Practices** - 8 DO's and 8 DON'Ts for setup

✅ **Related Links** - Cross-references to:

## Content Highlights

### Example: Leave Credit Issue
```markdown
## Phase 3.2: Initialize Leave Credits

**Critical**: Each employee must have a Leave Credit record for
each leave type, or they cannot request that type.

Why it matters:
- Without a credit record, employee cannot request that leave type
- System prevents over-requesting using credit balance
- Balance is auto-deducted when leave is approved
```

### Example: Setup Order
```markdown
## What Needs to Be Configured

| Phase | What | Who | Why |
|-------|------|-----|-----|
| 1. Foundation | Organization, access groups | Admin | Required for all users |
| 2. Users | Employee records, managers | HR Admin | Employees need accounts |
| 3. Leave System | Leave types, leave credits | HR Admin | Before leave requests work |
| 4. Scheduling | Shift types, employee schedules | Manager | Before clock-in works |
| 5. Payroll | Pay cycles, pay types, compensation | HR Admin | Before payroll works |
```

### Example: Error Scenarios
```markdown
### ❌ "Employees Can't Clock In"
**Cause**: No schedule created for that employee/date

**Solution**:
1. Go to **Scheduling**
2. Create a schedule for the employee for that date
3. Employee can then clock in
```
