# Welcome to Kando

**Kando** is your complete workforce management solution. Whether you're tracking time, managing leave, creating schedules, or processing payroll, Kando makes it simple and efficient.

## Get Started in 3 Steps

### Step 1: Choose Your Role
Select from the guide that matches your job:

- 👤 **Employee** - Track your time, request leave, view your schedule
- 👨‍💼 **Manager** - Manage your team, approve requests, create schedules
- 👨‍💻 **HR Administrator** - Set up the system, manage users, configure policies

### Step 2: Find Your Task
Each role has guides for common tasks:

**Employees**:
- How to clock in and out
- How to submit a timesheet
- How to request leave
- How to view your schedule
- How to check your payslip

**Managers**:
- How to view team timesheets
- How to approve leave requests
- How to create schedules
- How to generate reports
- How to manage overtime

**HR Administrators**:
- How to set up the system
- How to add users
- How to configure leave policies
- How to set up pay structures
- How to process payroll

### Step 3: Follow the Steps
Each guide provides clear, numbered instructions to complete your task.

## Browser & Device Support

Kando works on:
- ✅ Desktop (Chrome, Safari, Firefox, Edge)
- ✅ Tablet (iPad, Android tablets)
- ✅ Mobile (iPhone, Android phones)

**Recommended**: Desktop or tablet for best experience. Mobile works, but some features are optimized for larger screens.

## Tips for Success

✅ **DO**:
- Read the Getting Started section if you're new
- Use the search function to find topics
- Follow workflows step-by-step
- Take screenshots if you're stuck (for support)
- Check back if things change

❌ **DON'T**:
- Skip warning messages
- Assume features work without trying
- Forget to submit or approve requests
- Ignore deadline notifications
- Hesitate to ask for help

## System Requirements

**Minimum**:

**Recommended**:
- Broadband internet connection

- Latest browser version

## What is Kando?

Kando helps organizations manage:

| Feature | What It Does |
|---------|------------|
| **Time & Attendance** | Clock in/out, track work hours, build timesheets |
| **Leave Management** | Request leave, track balance, manage absences |
| **Scheduling** | Create shifts, manage schedules, handle requests |
| **Payroll** | Calculate pay, process payroll, generate payslips |
| **Approvals** | Review and approve requests, manage workflows |
| **Reports** | View data, generate reports, track metrics |
